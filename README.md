# Pipeline Tesouro Direto AWS 🚀

### 🚧 Projeto em desenvolvimento

Este projeto está em construção e faz parte do meu portfólio de Engenharia de Dados.

O objetivo é desenvolver um pipeline automatizado para ingestão, transformação e análise de preços e taxas dos títulos do Tesouro Direto, utilizando Python e serviços AWS.

**Status atual:** Etapa 5/7 — Implantação AWS e automação.

A documentação técnica, a arquitetura e as evidências serão atualizadas conforme a evolução do projeto.
